Linear equations and linear functions are the core of the SAT's Algebra domain, and they appear inside many other questions too: systems, inequalities, and word problems about cost or distance. If these skills are automatic, you save time across the whole Math section.

This guide covers the linear question types the SAT asks most, with worked examples whose answers were verified by code.

## Solving a linear equation in one variable

The method is always the same: collect the x terms on one side, the numbers on the other, then divide.

**Example 1.** If 9x − 15 = −6x + 45, what is the value of x?

Add 6x to both sides: 15x − 15 = 45. Add 15: 15x = 60. Divide: **x = 4**.

Check it: 9(4) − 15 = 21 and −6(4) + 45 = 21. Both sides match. That check takes a few seconds and catches sign errors, which are the most common reason students miss easy linear questions.

**Example 2, with fractions.** If x/3 + 2 = 5, what is x?

Subtract 2: x/3 = 3. Multiply by 3: **x = 9**. When an equation has several fractions, multiply every term by the common denominator first so the fractions disappear.

## When a linear equation has no solution or infinitely many

The SAT sometimes asks for a constant that makes an equation impossible or always true.

**Example 3.** For what value of k does 3(x + 2) = 3x + k have infinitely many solutions?

Distribute: 3x + 6 = 3x + k. The x terms are the same on both sides, so the equation is always true only if the constants match: **k = 6**. For any other k, the equation becomes something like 6 = 7, which is never true, so it has no solution.

The rule: if the x terms cancel, compare the constants. Equal constants mean infinitely many solutions; different constants mean no solution.

## Finding the slope from two points

Slope = change in y ÷ change in x = (y₂ − y₁) ÷ (x₂ − x₁).

**Example 4.** A linear function f satisfies f(−5) = 0 and f(−4) = 2. What is the value of f(7)?

Slope: (2 − 0) ÷ (−4 − (−5)) = 2 ÷ 1 = 2. Use one point to find the intercept: 0 = 2(−5) + b, so b = 10. The function is f(x) = 2x + 10, and f(7) = 2(7) + 10 = **24**.

**Example 5.** A linear function f satisfies f(−1) = 4 and f(0) = 2. What is f(10)?

Here f(0) = 2 hands you the y-intercept directly. Slope: (2 − 4) ÷ (0 − (−1)) = −2. So f(x) = −2x + 2, and f(10) = −20 + 2 = **−18**. Whenever one of the given points has x = 0, its output is b.

Slope from a table works the same way: pick any two rows and divide the change in output by the change in input. If the slope isn't the same between every pair of rows, the relationship isn't linear.

## Reading slope and intercept in context

Word problems give you a linear model and ask what one of its numbers means.

**Example 6.** A phone plan's monthly cost, in dollars, is C = 0.15m + 20, where m is the number of minutes used. What does 20 represent?

The **20 is the cost when m = 0**: a fixed monthly fee of $20. The **0.15 is the rate**: each additional minute adds $0.15. A good habit is to read the units out loud: "0.15 dollars per minute" and "20 dollars no matter what."

The SAT also asks the reverse: given a situation, which equation models it? Find the starting value (that's b) and the amount of change per unit (that's m). For example, a tank that starts with 300 liters and drains 12 liters per minute is modeled by V = 300 − 12t.

## Parallel and perpendicular lines

- **Parallel lines** have equal slopes. A line parallel to y = 3x − 7 also has slope 3.
- **Perpendicular lines** have slopes that are negative reciprocals. A line perpendicular to y = 3x − 7 has slope −1/3.

If a line is given in standard form, Ax + By = C, its slope is −A/B. For 2x + 5y = 10, the slope is −2/5.

## Common mistakes with linear equations and functions

- **Dropping a negative sign** when moving terms. Write each step; don't do two moves in your head.
- **Mixing up the order in the slope formula.** Keep the same point first in both the top and the bottom.
- **Confusing the rate with the starting value** in word problems. The number multiplied by the variable is the rate.
- **Not checking the answer.** Plugging x back in is the fastest error check on the test.

## Frequently asked questions

### How do you find the slope on the SAT?

Divide the change in y by the change in x between two points: (y₂ − y₁) ÷ (x₂ − x₁). For a line in the form y = mx + b, the slope is m; for Ax + By = C, it's −A/B.

### What does the y-intercept mean in an SAT word problem?

It's the value of the output when the input is zero: usually a starting amount, a fixed fee, or an initial quantity.

### When does a linear equation have no solution?

When the x terms cancel and the constants left on each side are different, such as 3x + 6 = 3x + 7. If the constants are equal, every x works.

### Are linear equations a big part of SAT Math?

Linear equations, linear functions, systems, and inequalities make up the Algebra domain, one of the four Math domains. Linear thinking also appears in many word problems in other domains.

### Should I use Desmos for linear equations?

Graphing is helpful for checking answers and for systems, but most one-variable linear equations are faster by hand. Practice both so you can choose quickly.
